# L.A.B Prompt Catalog

L.A.B用に再構築したデザイン・プロンプトカタログです。

## ローカル確認

```sh
python3 -m http.server 8765 --directory .
```

ブラウザーで `http://127.0.0.1:8765/` を開いてください。`index.html` を直接開くと、ブラウザーの制限によりJSON読み込みが失敗する場合があります。

## 収録内容

- デザイン例: 446件
- カテゴリー: 9種類
- 各作例の本画像・サムネイル・プロンプトJSONをローカル保存

## 公開時

`lab-catalog` ディレクトリ全体を静的サイトの公開ルートとして配信します。
